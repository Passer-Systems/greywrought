# Greywrought UI Icons

Individual transparent PNG assets extracted from the generated UI sheets.

## Folders
- `spells/512/` — 16 game-ready spell/ability icons
- `items/512/` — 16 game-ready item/inventory icons
- `menu/512/` — 14 game-ready menu/utility icons
- `*/source-crops/` — tight native-resolution crops preserving the original generated pixels

The `512` versions are transparent 512×512 PNGs with each icon centered and aspect-ratio preserved.
